CRM 시스템 구축

2025.11 ~ 2026.05

프로젝트 개요

고객 정보, 영업 견적, 계약 파이프라인 및 결재 이력을 일체형으로 통합 관리하기 위한 **신규 CRM(Customer Relationship Management) 구축 프로젝트**입니다.

영업 담당자가 영업 기회 발굴부터 계약 체결까지의 워크플로우를 효율적으로 관리할 수 있도록 견적 등록·조회, 계약 모니터링, 전자결재 연동 모듈을 개발하였습니다.

Vue.js와 AG-Grid 중심의 프론트엔드 및 Spring Boot REST API를 기반으로 구축하였으며, 사용자 업무 동선을 고려한 Split UI 적용과 대용량 조회 성능 최적화를 완료했습니다.

기술 스택

Java Spring Boot Vue.js PostgreSQL REST API AG-Grid Git

담당 업무

  • 고객사·프로젝트 연계 견적 등록 및 수정 처리 모듈 개발
  • AG-Grid 기반 다기능 견적 조회 및 필터링 파이프라인 구축
  • 계약 상태 파이프라인 및 계약 이력 조회 모듈 개발
  • Spring Boot 기반의 고성능 RESTful API 아키텍처 설계 및 구현
  • Vue.js 반응형 UI 개발 및 컴포넌트 단위 REST API 바인딩
  • PostgreSQL Complex Query 작성, SQL 튜닝 및 데이터 정합성 보장
  • 현업 요구사항 분석, UX/UI 개선 및 장애 대응 지원

주요 기능

견적 등록 기능

고객사 및 영업 프로젝트 기반의 상세 견적 데이터를 체계적으로 등록·수정하는 모듈입니다.

  • 고객사 매핑 및 프로젝트 연계 기반 견적 데이터 트랜잭션 구현
  • 견적 세부 품목별 단가·수량·가공비 연산 및 최종 금액 자동 산출
  • 입력 값 유효성 검증(Validation) 및 예외 처리 핸들러 적용
  • 견적 상태 변경 및 변경 이력 추적 REST API 구축
  • 견적 문서 데이터 히스토리 관리 및 버전 트래킹 기능 구현

견적 조회 기능

AG-Grid를 활용해 다량의 견적 데이터를 빠른 속도로 탐색·검색할 수 있는 반응형 화면입니다.

  • AG-Grid Enterprise 기반 대용량 견적 목록 컴포넌트 구축
  • 견적번호, 고객사명, 프로젝트명 복합 조건 실시간 검색 구현
  • 컬럼별 동적 정렬, 멀티 필터링 및 컬럼 피벗팅 기능 연동
  • 견적 상세 내역 및 품목 리스트 조회를 위한 팝업/모달 모듈 개발
  • 검색 편의성 극대화를 위한 사용자 맞춤 UI 레이아웃 구성

계약 조회 기능

체결된 계약 현황과 상태별 진행 파이프라인을 다각도로 조회 및 추적합니다.

  • 계약번호 및 거래처 기준 멀티 파라미터 검색 기능 구축
  • 계약 상태(승인대기·체결·파기 등)별 조건 필터링 구현
  • 계약 상세 정보 및 하단 계약금액/첨부파일 통합 폼 구성
  • 견적 데이터와 계약 정보 간 하이퍼링크 기반 연계 조회 파이프라인 구현

기안문서함 기능

내부 전자결재 워크플로우와 연동하여 결재 기안, 진행 상태 모니터링을 제공합니다.

  • 기안/결재 문서 목록 및 상세 페이지 Split View 구성
  • 결재 양식, 승인 상태, 문서번호 기반 다차원 조건 검색 지원
  • 결재선(기안-검토-승인) 실시간 이력 및 열람/참조자 트래킹 구현
  • 휴가신청서, 지출결의서 등 양식 유형별 결재 본문 동적 렌더링 엔진 적용

주요 화면

견적 등록

견적 목록과 상세 입력 폼을 좌우 분할 레이아웃으로 구성하였습니다. 견적 기간·타입·담당자 등 다양한 검색 조건을 제공하며, 첨부파일 업로드와 견적 비용 리스트 관리 기능을 함께 제공합니다.

견적 조회

AG-Grid 기반의 견적 목록 조회 화면입니다. 거래처구분·견적타입·담당자 조건 검색을 지원하며, 하단에 견적금액 리스트와 합계를 함께 표시합니다.

기안문서함

기안 문서 목록과 결재 상세 정보를 좌우 분할로 표시합니다. 결재 이력(결재선)과 열람/참조자 정보를 직관적으로 확인할 수 있으며, 결재내용(휴가 시작일·종료일·사유 등)을 양식별로 렌더링합니다.

계약 조회

계약 목록 그리드와 하단 상세 폼을 수직으로 구성하였습니다. 계약 기간, 거래처구분, 계약타입, 승인상태 조건 검색을 지원하며, 계약금액 리스트와 첨부파일 리스트를 하단 좌우에 나란히 배치하였습니다.

트러블 슈팅

대용량 견적/계약 데이터 조회 및 복합 조인 SQL 성능 최적화

견적 및 계약 누적 데이터 증가에 따른 N+1 조인 지연 현상과 AG-Grid 초기 렌더링 속도 저하 문제를 해결했습니다.

문제 상황

  • 견적/고객사/품목 테이블 간 복합 조인으로 인한 Response Time 지속 상승
  • 사용자 조건 검색 시 데이터 Full Scan으로 인한 DB CPU 병목 발생
  • 프론트엔드 AG-Grid 전체 로딩 시 메모리 사용량 증가로 인한 화면 버벅임 현상

원인 분석

  • `EXPLAIN` 실행계획 분석 결과 검색 조건 컬럼 인덱스 미적용 확인
  • `SELECT *` 사용으로 인한 불필요한 대용량 LOB/텍스트 컬럼 중복 조회 발견
  • 정렬(`ORDER BY`) 시 Temp Tablespace를 사용하는 Disk Sort 발생 확인

개선 작업

  • `고객사ID`, `견적일자`, `담당자ID` 복합 인덱스(Composite Index) 생성
  • 필요한 컬럼만 명시적으로 조회하도록 SQL 리팩토링 및 불필요한 OUTER JOIN 제거
  • AG-Grid Infinite Scrolling(무한 스크롤) / Server-side Row Model 적용으로 초기 조회 로드 최소화
  • 자주 조회되는 마스터 코드 성격 데이터에 Redis / In-memory Caching 개념 도입

결과

  • 목록 조회 응답 속도 및 그리드 초기 렌더링 속도 대폭 개선
  • DB Query Latency 축소 및 검색 반응성 향상

프로젝트 성과

  • 견적 수기 작성 및 개별 관리 프로세스를 CRM 표준 시스템으로 수립하여 영업 업무 처리 효율 대폭 향상
  • 고객사별 영업 이력, 견적, 계약 데이터를 통합 수집·조회할 수 있는 파이프라인 구축
  • 계약 모니터링 및 상태 추적 모듈을 구축하여 영업 누락 방지 및 운영 업무 지원 강화
  • RESTful API 표준 설계 및 DTO/Entity 분리를 통한 백엔드 데이터 레이어 모듈화 완수
  • AG-Grid Enterprise를 활용한 대용량 데이터 리스트 UI 최적화 및 UX 고도화
  • PostgreSQL 쿼리 실행계획 분석, 인덱스 최적화 및 튜닝을 통한 대용량 데이터 처리 기술 확보
  • 요구사항 수집, 데이터 모델링, 개발, 단위/통합 테스트, 최종 배포에 이르는 구축 Lifecycle 전반 완수
