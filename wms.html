WMS 시스템 고도화

2023.09 ~ 2023.12

프로젝트 개요

입고, 출고, 재고 관리 등 창고 물류 프로세스 전반을 지원하는 WMS(Warehouse Management System) 구축 및 고도화 프로젝트입니다.

Java와 Spring Boot 기반 백엔드 서비스 및 Vue.js 화면 개발을 담당했으며, 로케이션/존 단위의 실시간 재고 추적 기능과 복합 쿼리 최적화를 수행하였습니다.

기술 스택

Java Spring Boot Vue.js PostgreSQL MyBatis REST API GitLab

담당 업무

  • 입고예정/입고등록 및 출고예정 조회 화면 및 REST API 개발
  • 센터/로케이션별 재고 조회 좌우 분할 연계 화면 개발
  • 상품별 현재고 및 이동/조정 진행 중 재고 집계 로직 개발
  • PostgreSQL 복합 인덱스 설계 및 쿼리 성능 튜닝

주요 화면

입고예정 관리

상단 목록과 하단 상품 상세 연계 조회를 지원합니다.

센터별 재고 조회

센터 및 로케이션별 가용 재고 현황을 한눈에 파악합니다.

트러블 슈팅

다중 집계 쿼리 성능 개선 및 수력 정합성 확보

문제 상황

  • 재고 집계 연산 시 다중 GROUP BY로 인해 응답 속도가 지속 지연됨
  • 동시 입출고 진행 시 NULL 값 집계 누락으로 일부 수량 불일치 발생

개선 작업

  • 센터코드-상품코드 복합 인덱스 신설 및 서브쿼리를 인라인 뷰로 최적화
  • NVL/COALESCE 함수 보정으로 NULL 예외 처리 보완

결과

  • 재고 집계 조회속도 향상 및 재고 데이터 정합성 100% 확보

프로젝트 성과

  • Spring Boot + Vue.js 기반 웹 서비스 구조 습득
  • 입출고 및 로케이션 재고 관리 도메인 역량 확보
  • 대용량 재고 쿼리 최적화 및 정합성 검증 경험 체득
