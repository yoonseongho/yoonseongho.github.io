운송관리시스템 (TMS) 고도화

2024.01 ~ 2025.01 (1년)

프로젝트 개요

보세·항공·내륙 복합 운송 프로세스를 정밀 통제하는 엔터프라이즈 **TMS 고도화 프로젝트**입니다. 운임/선사/차량/기사/샤시 등 물류 핵심 마스터 데이터를 체계화하고, 실시간 배차 모니터링 및 컨테이너 단위 정산·수익성 분석 환경을 구축했습니다.

기술 스택

Java Spring Boot Vue.js PostgreSQL MyBatis REST API

담당 업무 Summary

  • 마스터 데이터 구축: 운임, 선사, 차량(1.4만건), 기사, 샤시 장비 마스터 API 및 관리 화면 개발
  • 운송 및 배차 통제: Location/Depot 거점 관리 및 일자/협력사별 가용차량 실시간 배차 모듈 구현
  • 정산 및 분석: 월간 운송 실적 집계 및 컨테이너별 매출/비용/이익 Pivot 분석 대시보드 구축
  • 성능 최적화: PostgreSQL 대용량 쿼리 튜닝 및 Server-side Pagination 도입

주요 기능 및 성과

1. 기준정보(Master Data) 통합 관리

보세/항공 운임코드(220여건), 선사/세관코드(920여건) 다차원 파라미터 관리 모듈 개발

  • 차량(14,722건) 및 기사(5,014건) 프로필의 Server-side Pagination 처리로 조회 속도 개선
  • 컨테이너 샤시 장비의 정비 이력 및 다중 검사 주기(사무소/최종/만료일) 연계 추적
  • Location/Depot 거점 매핑 및 COPINO EDI 연계 속성 관리 체계 구축

2. 실시간 배차 및 월간 실적 분석 대시보드

일자·부서·협력사별 가용 배차 현황 파악 및 월 단위 운송 트랜잭션 실시간 집계

  • 운임 항목별 매출(운송료/부가/부대)/비용 분류 및 Pivot 집계 Engine 구현
  • W/O No., CNTR No. 기준 컨테이너 단위 손익(청구 대비 비용) 다차원 밀착 분석

주요 화면

운임코드 관리

상단 조건 입력 및 하단 220여 건의 운임코드 목록 연계 관리

선사코드 관리

선사·세관코드·Main VAN사 등 920여 건의 마스터 조회 및 페이징

차량코드 관리

기본/추가/FPIS 탭 구조 및 1.4만 건 차량 Server-side 페이징

차량기사 관리

5천여 건 기사 프로필 관리 및 모바일 APP 연동 전송 기능

샤시코드 관리

샤시 장비 상태 및 다중 검사만료일 통합 관리

샤시정비 관리

차량영업번호 연계 샤시 정비 이력 및 비용 추적

Location / Depot 관리

좌측 Location - 우측 Depot 연계 및 EDI 통신 설정 관리

월간 실적 조회

월 단위 운송료/부가/부대 항목별 매출·비용 Pivot 집계

컨테이너별 실적

I/O 구분, 철송 여부 조건별 컨테이너 실적 현황 조회

컨테이너 청구·비용 대비

W/O·CNTR 단위 손익 산출 및 청구 대비 비용 다차원 분석

가용차량 관리

일자·부서·협력사별 가용 배차 현황 실시간 모니터링

트러블 슈팅 (Problem Solving)

1. 1.4만건 대용량 차량/기사 데이터 조회 성능 최적화

문제 및 원인

다중 JOIN 실행 시 Query Timeout 발생 및 Front-end 그리드 바인딩 과부하

해결 방안

  • 조회 조건 컬럼 복합 인덱스 생성 및 불필요한 Inline View 리팩토링
  • PostgreSQL `OFFSET-LIMIT` 기반 Server-side Pagination 도입

결과

초기 데이터 로딩 속도 단축 및 서버 I/O 부하 절감

2. 월간 실적 집계 소계/합계 불일치 조치

문제 및 원인

특정 W/O 조건 연산 시 `NULL` 값 산출 항목 미처리로 집계 수치 오차 발생

해결 방안

  • SQL 집계 내 `COALESCE` 처리를 통한 NULL 예외 보정
  • CASE-WHEN Pivot 연산 조건 재설계 및 검증 테스트 케이스 수행

결과

실적 및 컨테이너 분석 데이터 집계 정확도 100% 확보
