창고관리시스템 (WMS) 고도화

2023.09 ~ 2023.12 (4개월)

Vue.js 기반 물류 업무 화면 개발 · 재고 데이터 조회 · 대용량 그리드 처리 개선

프로젝트 개요

입고·출고·재고 등 창고 물류 업무 전반을 지원하는 창고관리시스템(WMS) 고도화 프로젝트입니다. Vue.js 기반의 업무 화면을 개발하고, 센터·존·로케이션별 재고 정보와 입고·출고·이동·조정 현황을 조회할 수 있도록 기능을 구현했습니다.

상품과 재고 상세 정보를 연계하는 화면, LOT 및 유통기한 관리, 장기보관 재고 조회 기능을 통해 사용자가 필요한 물류 정보를 조건별로 확인하고 업무를 처리할 수 있도록 지원했습니다.

기술 스택

Vue.js JavaScript HTML / CSS REST API Java Spring Boot PostgreSQL MyBatis

프론트엔드 담당 업무

  • 업무 화면 개발: 입고예정·입고등록·출고예정·재고 조회 등 물류 업무별 화면 구현
  • 데이터 연계 및 화면 구성: 상품 선택과 센터·로케이션별 상세 정보 조회를 연결한 Master-Detail UI 구성
  • 조회 조건 및 데이터 표시: 재고 상태, 보관일수, 상품 및 물류 거점 기준으로 데이터를 조회하고 표시하는 기능 개발
  • 수량 및 상태 정보 처리: 포장 단위 환산, LOT·유통기한 정보, 입출고 진행 상태를 화면에서 확인할 수 있도록 기능 구현
  • 대용량 화면 처리 개선: 재고 집계 쿼리와 인덱스를 검토하고 대량 데이터 조회 및 그리드 렌더링 부담 개선

주요 프론트엔드 기능

1. 입고·출고 업무 화면

입고예정 정보부터 실제 입고 등록, 출고예정 및 확정 수량 확인까지 물류 업무 단계별 화면을 구현했습니다.

  • 입고예정 목록과 상품 상세 정보를 연결한 조회 화면 개발
  • 로케이션·LOT·생산일자·유통기한 등 입고 관련 정보 입력 및 확인 기능 구현
  • PLT / BOX / CS / EA 포장 단위별 수량 환산 정보 표시
  • 출고 상태 및 출고 대상 상품 정보를 확인할 수 있는 화면 구성
  • 입고·출고 데이터의 상태 및 확정 수량 확인 기능 구현

2. Master-Detail 기반 재고 조회 UI

상품 목록과 상세 재고 정보를 연계하여 사용자가 선택한 상품의 센터·존·로케이션별 재고를 확인할 수 있도록 화면을 구성했습니다.

  • 상품 목록과 상세 재고 영역을 분리한 Split UI 구현
  • 상품 선택에 따른 센터 및 로케이션별 재고 상세 정보 연계
  • 일반·보류·불량 등 재고 상태별 수량 표시
  • 보관일수 기준 장기보관 상품 조회 기능 구현
  • 상품 및 물류 거점별 재고 정보를 구분하여 확인할 수 있도록 화면 구성

3. 재고 수불 현황 통합 조회

현재고와 입고·출고·반출·이동·조정 등 진행 중인 수불 정보를 함께 확인할 수 있도록 재고 현황 화면을 개발했습니다.

  • 현재고 및 진행 중인 수불 수량을 통합 조회하는 화면 구현
  • 수불 유형별 데이터와 재고 상태를 구분하여 표시
  • 집계 데이터의 조회 조건과 화면 표시 결과를 확인할 수 있도록 기능 구성

주요 화면

입고예정 관리

입고예정 목록과 연계 상품 정보를 구분하여 조회하고 환산 수량 확인

입고등록 관리

로케이션·LOT·유통기한 정보 입력 및 실제 입고 확정 처리

출고예정 조회

출고 진행 상태와 보세 여부 등 조건별 출고예정 정보 조회

출고예정 상품정보

출고 대상 상품의 바코드 정보 연계 및 확정 수량 확인

센터별 재고 조회

상품 목록과 센터·로케이션별 상세 재고를 연계한 Master-Detail UI

장기보관 상품 조회

보관일수 기준 장기보관 상품 조회 및 재고 상태 확인

상품별 현재고 현황

일반·보류·불량 재고 상태별 집계 및 로케이션별 수량 조회

진행 중인 재고 현황

현재고와 입고·출고·이동·조정 등 진행 중인 수불 수량 통합 조회

트러블 슈팅 (Problem Solving)

1. 대용량 재고 조회 시 화면 렌더링 부담 개선

문제 및 원인

재고 집계에 다중 GROUP BY 및 SUM 연산이 사용되어 조회가 지연되고, 많은 양의 데이터가 화면에 전달되면서 그리드 렌더링과 스크롤 반응이 저하되는 문제가 있었습니다.

해결 과정

  • 센터·상품·존 등 주요 조회 조건에 사용되는 컬럼의 인덱스 검토
  • 불필요한 서브쿼리와 집계 로직을 점검하여 SQL 조회 구조 개선
  • 대량 데이터 표시 시 브라우저 렌더링 부담을 줄이기 위한 Virtual Scroll 등 화면 처리 방식 검토 및 적용

결과

데이터 조회와 화면 렌더링 과정의 처리 부담을 줄이고, 재고 조회 화면의 사용성과 대량 데이터 처리 효율 개선에 기여했습니다.

2. 수불 상태별 재고 집계 불일치 개선

문제 및 원인

수불 상태별 조건 분기가 충분히 반영되지 않거나 집계 과정에서 NULL 값이 처리되지 않아 진행 재고 수량에 차이가 발생했습니다.

해결 과정

  • COALESCE를 적용하여 NULL 값에 대한 집계 기준 보완
  • 입고·출고·이동·조정 등 수불 상태별 조건 분기 로직 점검
  • 다양한 수불 상태와 수량 조합을 기준으로 집계 결과 검증

결과

수불 상태 및 NULL 값에 따른 집계 예외를 보완하여 현재고와 진행 재고 데이터의 일관성을 개선했습니다.

프로젝트 성과 및 기술 역량

  • 프론트엔드 화면 개발: 입고·출고·재고 업무를 위한 다양한 데이터 조회 및 관리 화면 구현
  • UI 구성 및 데이터 연계: Master-Detail 구조를 활용해 상품 목록과 상세 재고 정보를 연결
  • 대용량 데이터 처리: 데이터베이스 조회 구조와 화면 렌더링 부담을 함께 검토하여 조회 효율 개선
  • 데이터 표시의 일관성: 수불 상태별 집계와 NULL 처리 로직을 보완하여 화면에 표시되는 재고 정보의 일관성 개선
  • 물류 도메인 경험: LOT·유통기한·재고 상태·센터·로케이션 등 WMS 핵심 데이터에 대한 이해 축적
