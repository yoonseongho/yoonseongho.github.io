CRM 시스템 구축

2025.11 ~ 2026.05 (7개월)

Vue.js · AG-Grid 기반 영업 데이터 관리 화면 개발 및 조회 UI 개선

프로젝트 개요

고객 정보, 영업 견적, 계약 정보 및 전자결재 이력을 통합 관리하기 위한 CRM(Customer Relationship Management) 시스템 구축 프로젝트입니다. Vue.js 기반으로 견적 등록·조회, 계약 상태 확인, 결재 문서 조회 등 업무에 필요한 화면을 개발했습니다.

AG-Grid를 활용해 다량의 견적 및 계약 데이터를 표 형태로 표시하고, 검색 조건과 상세 정보 영역을 구성해 사용자가 필요한 데이터를 효율적으로 탐색할 수 있도록 구현했습니다.

Spring Boot REST API와 화면 데이터를 연동했으며, SQL 조회 구조와 그리드 데이터 표시 과정을 점검해 목록 조회 및 화면 응답성 개선에 기여했습니다.

기술 스택

Vue.js JavaScript HTML CSS AG-Grid REST API Java Spring Boot PostgreSQL Git

프론트엔드 담당 업무

  • Vue.js 기반 UI 개발: 업무별 화면과 컴포넌트를 구성하고 REST API 데이터를 화면에 연결
  • AG-Grid 데이터 테이블 구현: 견적 및 계약 목록, 컬럼 정렬, 조건별 필터링과 데이터 조회 화면 개발
  • 검색 및 상세 조회 인터페이스: 검색 조건과 상세 정보 영역을 구성해 사용자의 데이터 탐색 지원
  • Split View UI 구성: 목록과 상세 정보를 한 화면에서 확인할 수 있도록 분할형 레이아웃 구현
  • REST API 연동: 화면의 요청 조건과 API 응답 데이터를 연결하고 조회 결과 표시
  • 화면 및 데이터 조회 개선: 그리드 표시 과정과 SQL 실행계획을 점검해 불필요한 조회 및 표시 부담 개선
  • 요구사항 반영 및 이슈 대응: 현업 요청사항을 반영하고 UI 사용성과 화면 동작 점검

주요 프론트엔드 기능

1. 견적 등록 UI

고객사와 영업 프로젝트에 연결된 견적 정보를 등록하고 수정할 수 있도록 입력 폼과 관련 데이터 영역을 구성했습니다.

  • 고객사 및 프로젝트 정보와 연계된 견적 입력 화면
  • 품목별 단가, 수량, 가공비 등 견적 항목 표시 및 입력 처리
  • 입력값 검증과 예외 상황을 고려한 데이터 처리
  • 견적 상태와 변경 이력 확인을 위한 API 연동
  • 견적 목록과 상세 입력 폼을 함께 확인할 수 있는 화면 구성

2. AG-Grid 기반 견적 조회

다량의 견적 데이터를 탐색할 수 있도록 데이터 테이블 중심의 조회 화면을 개발했습니다.

  • 견적 목록을 표시하는 AG-Grid 기반 테이블 구현
  • 견적번호, 고객사명, 프로젝트명 등 검색 조건 구성
  • 컬럼 정렬 및 조건별 필터링 기능 제공
  • 견적 상세 정보와 품목 목록을 확인하는 팝업·모달 화면 구성
  • 견적 목록과 금액 정보를 함께 확인할 수 있는 레이아웃 구현

3. 계약 조회 및 상태 확인 UI

계약 현황과 진행 상태를 검색하고 상세 정보를 확인할 수 있는 데이터 조회 화면을 구현했습니다.

  • 계약번호와 거래처를 기준으로 한 검색 인터페이스 구성
  • 승인 대기, 체결, 파기 등 계약 상태별 필터링
  • 계약 목록과 상세 정보를 연결하는 조회 화면 구현
  • 계약 금액 및 첨부파일 정보를 확인하는 영역 구성
  • 견적 데이터와 계약 정보의 연계 조회 지원

4. 전자결재 문서함 UI

결재 문서 목록과 상세 내용을 연결해 문서 진행 상황을 한 화면에서 확인할 수 있도록 구성했습니다.

  • 문서 목록과 상세 내용을 함께 보여주는 Split View 구현
  • 문서번호, 결재 양식, 승인 상태를 기준으로 한 검색 기능
  • 결재 이력과 열람자·참조자 정보 표시
  • 휴가신청서, 지출결의서 등 문서 유형별 본문 표시

주요 화면

견적 등록

목록과 상세 입력 폼을 좌우로 배치했습니다. 검색 조건, 첨부파일 및 견적 품목 정보를 한 화면에서 확인하고 관리할 수 있도록 구성했습니다.

견적 조회

AG-Grid를 활용해 견적 데이터를 표 형태로 표시하고, 거래처 구분과 견적 유형, 담당자 등 조건에 따라 필요한 정보를 조회할 수 있도록 구현했습니다.

기안문서함

문서 목록과 상세 내용을 분할 화면으로 구성했습니다. 결재 이력과 열람·참조자 정보를 확인하고 문서 양식에 맞는 결재 내용을 표시하도록 구현했습니다.

계약 조회

계약 목록과 상세 정보를 상하 영역으로 구성했습니다. 계약 기간, 거래처, 계약 유형 및 승인 상태를 검색하고 계약 금액과 첨부파일 정보를 확인할 수 있도록 했습니다.

트러블 슈팅 (Problem Solving)

1. 대량 데이터 조회 시 그리드 화면 응답성 저하

문제 및 원인

견적 및 계약 데이터가 증가하면서 목록 조회가 느려지고, 그리드에 데이터를 표시하는 과정에서도 화면 반응이 지연되는 문제가 있었습니다.

해결 과정

  • 복합 JOIN 조회로 인해 시간이 소요되는 구간과 SQL 실행계획 점검
  • 검색 조건에 따른 인덱스 활용 여부 확인
  • 조회 화면에서 사용하는 컬럼을 중심으로 SQL 조회 항목 정리
  • 불필요한 JOIN을 검토하고 그리드 데이터 전달 및 표시 과정 점검
  • 반복 조회 데이터의 캐싱 적용 가능성 검토

결과

불필요한 데이터 조회를 줄이고 화면에 필요한 데이터를 중심으로 처리하도록 개선해 목록 조회와 그리드 초기 표시의 응답성 향상에 기여했습니다.

프로젝트 성과 및 기술 역량

  • 데이터 중심 UI 개발: 견적·계약·결재 데이터를 화면 목적에 맞게 구성하고 목록과 상세 정보를 연결
  • Vue.js와 REST API 연동: 서버 API 데이터를 프론트엔드 화면에 연결하고 조회 결과 표시
  • 데이터 테이블 및 검색 UI: AG-Grid를 활용해 검색, 정렬, 필터링 등 업무용 데이터 화면 구현
  • 사용자 관점의 화면 구성: 목록과 상세 정보를 함께 확인할 수 있는 레이아웃으로 정보 탐색 지원
  • 화면 성능 문제 분석: 데이터 조회 구조와 그리드 표시 과정을 함께 점검해 처리 흐름 개선
