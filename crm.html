CRM 시스템 구축 및 기능 개선

2025.11 ~ 2026.06

프로젝트 개요

고객 정보, 견적, 계약 이력을 통합 관리하기 위한 CRM(Customer Relationship Management) 시스템 구축 프로젝트입니다.

영업 담당자가 고객 및 프로젝트 정보를 보다 효율적으로 관리할 수 있도록 견적 등록/조회, 계약 조회, 기안문서함 기능을 개발하였습니다.

Vue.js 기반 프론트엔드와 Spring Boot 기반 REST API를 활용하여 표준화된 인터페이스를 구축하였으며, 예외 처리 강화 및 SQL 튜닝을 통해 시스템의 안정성과 응답 속도를 향상시켰습니다.

기술 스택

Java Spring Boot Vue.js PostgreSQL REST API AG-Grid Git

담당 업무

  • 고객사 및 프로젝트 기반 견적 등록/수정/조회 API 개발
  • 계약 조회 및 상태별 조회 기능 개발
  • 내부 결재선 및 기안문서함 워크플로우 개발
  • Vue.js + AG-Grid 기반 화면 구성 및 API 연동
  • PostgreSQL 쿼리 작성, 인덱스 설계 및 조회 최적화
  • 운영 중 발생 오류 분석, 예외 처리 로직 강화를 통한 재발 방지

주요 기능

견적 등록 기능

고객사 요청에 대한 견적 정보를 등록하고 관리할 수 있는 기능을 구현하였습니다.

  • 고객사 및 프로젝트 기반 견적 등록 기능 개발
  • 견적 품목별 금액 관리 및 필수 입력값 검증 로직 적용
  • 등록 데이터 이력 관리 및 변경 사항 추적 기능 구현

견적 조회 기능

등록된 견적 정보를 다양한 조건으로 검색하고 관리할 수 있는 화면을 개발하였습니다.

  • AG-Grid 기반 대용량 목록 조회 및 다중 조건 검색 구현
  • 정렬, 필터링, 상세 정보 조회 팝업 개발

계약 조회 기능

계약 정보 및 상세 내용을 통합 조회할 수 있는 기능을 개발하였습니다.

  • 계약 상태별 조회 및 견적/프로젝트 연계 데이터 조회 구현

기안문서함 기능

내부 결재 문서 기안 및 결재 현황을 파악하는 워크플로우를 구현하였습니다.

  • 결재선 이력 표시 및 양식별 결재내용 동적 렌더링 개발

주요 화면

견적 등록

견적 목록과 상세 입력 폼을 좌우 분할 레이아웃으로 구성하였습니다. 검색 조건 및 첨부파일 업로드 기능을 통합 제공합니다.

견적 조회

AG-Grid 기반 견적 목록 조회 화면입니다. 거래처/담당자 조건 검색 및 하단 견적 합계를 표시합니다.

기안문서함

기안 문서 목록과 결재선 정보를 표시하며 양식별 상태를 직관적으로 렌더링합니다.

계약 조회

계약 목록 그리드와 상세 폼을 수직 배치하여 계약 금액 및 첨부파일을 조회가 가능하도록 구현했습니다.

트러블 슈팅

대량 데이터 조회 성능 개선 및 쿼리 최적화

견적 데이터 증가로 인한 조회 응답 속도 저하 문제를 해결했습니다.

문제 상황

  • 여러 테이블 조인 시 발생한 Full Scan으로 인해 견적 목록 조회 속도 지연

원인 분석

  • EXPLAIN 분석을 통해 검색 조건 컬럼 인덱스 미적용 및 불필요한 서브쿼리 조인 확인

개선 작업

  • 자주 사용되는 검색 조건 컬럼 복합 인덱스 추가 및 불필요한 JOIN 구문 제거
  • SELECT 조회 컬럼 최소화 및 페이징 구조 개선

결과

  • 조회 응답 속도 기존 대비 30% 이상 향상 및 DB 서버 부하 절감

프로젝트 성과

  • 견적 등록부터 계약 관리까지의 수기 절차를 시스템화하여 영업 업무 처리 효율 향상
  • REST API 구조 최적화 및 데이터 검증 강화를 통해 장애 조치 시간(MTTR) 감소
  • AG-Grid 기반 고성능 데이터 그리드 연동 경험 확보
  • Vue.js + Spring Boot 기반 풀스택 시스템 개발 능력 입증
