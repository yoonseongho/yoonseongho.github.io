창고관리시스템 (WMS) 고도화

2023.09 ~ 2023.12 (4개월)

프로젝트 개요

입고·출고·재고 등 창고 물류 라이프사이클 전반을 통합 관리하는 **WMS 고도화 프로젝트**입니다. 센터/로케이션 단위의 실시간 재고 추적, LOT 및 유통기한 관리, 진행 중 수불(입/출/이동/조정) 현황 대시보드를 구축하여 재고 가시성을 극대화했습니다.

기술 스택

Java Spring Boot Vue.js PostgreSQL MyBatis REST API

담당 업무 Summary

  • 입/출고 프로세스: 입고예정·등록, 출고예정 및 연계 상품 정보 동적 바인딩 UI/API 구현
  • 재고 모니터링: 센터별 Split UI 재고 조회 및 장기보관 상품 필터링 모듈 개발
  • 수불 집계 대시보드: 현 재고와 진행 중인 수불(입/출/이동/조정) 트랜잭션 Pivot 집계 개발
  • 성능 최적화: PostgreSQL 복합 인덱스 적용 및 Vue.js Virtual Scroll 기법 활용

주요 기능

1. 입·출고 모듈 및 단위 환산 연산

센터그룹·고객사 기반 입/출고 워크플로우 제어 및 자동 단위 산출

  • PLT / BOX / CS / EA 환산 수량 자동 산출 로직 구현
  • LOT, 생산일자, 유통기한 및 잔여 유통일수 자동 계산 알고리즘 적용

2. 실시간 재고 추적 및 수불 집계 대시보드

센터·존·로케이션 단위 미시 재고 파악 및 수불 상태 통합 모니터링

  • Master-Detail(Split UI) 구조로 상품 클릭 시 로케이션별 재고 동적 렌더링
  • 보관일수 기준 장기보관 재고 추적 및 품질 속성(일반/보류/불량) 분류
  • 현재고와 진행 수량(입고/출고/반출/조정/이동) 통합 Pivot 조회 파이프라인 개발

주요 화면

입고예정 관리

상단 입고예정 목록과 하단 연계 상품(환산 수량) 분리 표시

입고등록 관리

로케이션, LOT, 유통기한 지정 및 실제 입고 확정 처리

출고예정 조회

출고 진행 상태 및 보세 여부 등 다중 조건 필터링

출고예정 상품정보

출고 대상 상품 바코드 매핑 및 확정 수량 정합성 확인

센터별 재고 조회

좌측 상품 마스터 - 우측 센터/로케이션별 재고 Split 연계 UI

장기보관 상품 조회

보관일수 임계값 기준 악성 재고 모니터링 및 추적

상품별 현재고현황

일반/보류/불량존 재고 품질 집계 및 로케이션별 수량 바인딩

진행중인 재고현황

현 재고와 수불 진행 수량(입/출/이동/조정) 한눈에 조회

트러블 슈팅 (Problem Solving)

1. 재고 집계 쿼리 및 Vue.js 그리드 DOM 병목 개선

문제 및 원인

다중 GROUP BY/SUM 연산 지연 및 대량 컬럼 바인딩 시 브라우저 스크롤 렉 발생

해결 방안

  • 센터/상품/존 조건절 대상 복합 인덱스(Composite Index) 생성
  • 불필요 서브쿼리를 Inline View로 통합 및 Vue.js Virtual Scroll 적용

결과

DB I/O 부하 절감 및 프론트엔드 그리드 스크롤 쾌적성 확보

2. 동시 수불 처리 시 진행재고 수량 불일치 조치

문제 및 원인

수불 진행 상태 조건 분기 로직 누락 및 PostgreSQL `NULL` 집계 예외 미비

해결 방안

  • `COALESCE` 적용으로 NULL 연산 보정 및 수불 상태 조건 케이스 구현
  • JUnit 기반 동시성 테스트 케이스 작성 및 검증

결과

동시 수불 환경에서도 재고 집계 정확도 100% 확보

프로젝트 성과

  • 재고 가시성 확보: 센터·존·로케이션 및 LOT 단위 실시간 재고 추적 체계 구축 완료
  • 수불 정합성 100%: 동시 입출고 상황에서도 수불 진행재고와 가용재고 연산 오차 제거
  • 운영 효율화: 장기보관 상품 추적 기능으로 창고 공간 활용도 개선 및 악성 재고 감소 기여
  • 대용량 성능 최적화: Complex Query 집계 연산 튜닝으로 대용량 재고 화면 조회 응답속도 향상
