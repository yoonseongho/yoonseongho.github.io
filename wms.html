WMS 시스템 고도화

2023.09 ~ 2023.12

프로젝트 개요

입고·출고·재고 등 물류창고 내 전 과정을 통합 관리하는 엔터프라이즈 **WMS(Warehouse Management System) 고도화 프로젝트**입니다.

센터그룹·센터·고객사 기반의 입고예정/입고등록 및 출고예정 관리 프로세스를 구축하고, 센터·존·로케이션 단위의 실시간 재고 추적 및 장기보관 상품 모니터링 체계를 구현하였습니다.

또한 상품별 현재고 현황 및 진행 중인 재고 변동 흐름(입고·출고·이동·조정)을 한눈에 파악할 수 있는 대시보드형 집계 시스템을 구축하여 재고 가시성 및 수불 정합성을 극대화하였습니다.

기술 스택

Java Vue.js Spring Boot PostgreSQL MyBatis REST API GitLab

담당 업무

  • 입고예정 등록·수정·조회 REST API 및 UI 파이프라인 구축
  • 입고등록 프로세스 및 마스터 상품정보 실시간 연계 기능 개발
  • 출고예정 모니터링 및 단계별 출고 현황 조회 기능 개발
  • 센터별 재고 연계 조회 화면 구축 (좌우 Master-Detail 분할 구조 구현)
  • 보관일수 기준 장기보관 상품 필터링 및 모니터링 기능 구축
  • 상품별 현재고 현황 및 로케이션 단위 재고 상세 연계 조회 개발
  • 진행중인 재고현황 통합 조회 및 수불 유형별 트랜잭션 집계 로직 개발
  • Vue.js + Spring Boot 기반 REST API 설계 및 PostgreSQL Complex Query 최적화

주요 기능

입고예정 관리

센터그룹·센터·고객사 다중 조건을 기반으로 입고예정 데이터를 체계적으로 관리하는 모듈입니다.

  • 센터그룹·센터·고객사·입고처 기반 멀티 파라미터 입고예정 검색 구현
  • 입고예정일 기간 검색 및 입고예정상태 플래그 필터링 적용
  • 센터코드·고객사코드·주문번호·입고벤더·입고처 등 핵심 속성 데이터 바인딩
  • 수불코드·입고작업구분·주문생성구분·차량번호·입고전표번호 등 트랜잭션 속성 관리
  • 상단 입고예정 목록과 하단 연계 상품정보(환산 예정수량/등록수량) 동적 바인딩
  • 팔레트(PLT)·박스(BOX)·케이스(CS)·낱개(EA) 단위 환산 수량 자동 산출 로직 구현

입고등록 관리

입고예정 확정건에 대한 실체 입고 등록 및 상품 물성 정보를 실시간 바인딩 처리합니다.

  • 입고예정 데이터 연동을 통한 빠른 입고 확정 및 등록 처리 모듈 구현
  • 입고일자·고객사주문일·고객사주문번호 등 입고 이력 트랜잭션 데이터 관리
  • 상품코드·상품명·존코드·로케이션 매핑 기반 상품 정보 실시간 등록
  • 상품 LOT, 생산일자, 유통기한, 소비기한 및 잔여 유통기한 일수 자동 계산 알고리즘 적용
  • 환산 예정수량 대비 실제 입고 등록 수량 정합성 검증 기능 적용
  • 저장·등록·초기화 트랜잭션 연계 워크플로우 제어 로직 구현

출고예정 조회

출고 라이프사이클에 맞춰 출고예정 목록과 하단 상품 상세 정보를 정밀하게 모니터링합니다.

  • 센터그룹·센터·고객사·출고처 기반 출고예정 동적 쿼리 모듈 구현
  • 출고예정일 기간 지정 및 출고 진행 상태 단계별 필터링 기능 적용
  • 고객사코드·주문번호·출고진행상태·출고배치·보세여부·출고처코드 목록 조회
  • 고객사주문일·고객사주문번호·출고작업구분·발송자코드 데이터 파라미터 처리
  • 하단 상품 연계 그리드에 고객라인번호·상품코드·상품명·검수용 바코드 매핑 표시
  • 환산 예정수량·등록수량(PLT/BOX/CS/EA) 및 최종 확정수량 정합성 관리

센터별 재고 조회

상품별 전체 재고 수량과 센터·로케이션 단위의 미시 재고를 연계 조회하는 Split UI 화면입니다.

  • 센터그룹·고객사·상품 조건 기반의 다차원 재고 모니터링 구현
  • 좌측: 상품 마스터 정보(상품코드·상품명·총수량·센터총수량) 그리드 구성
  • 우측: 선택 상품의 센터별 세부 정보(센터·입고일자·존·로케이션·재고수·가용재고수) 동적 연계
  • 상품 클릭 이벤트 기반 우측 센터/로케이션별 재고 상세 즉시 렌더링 최적화

장기보관 상품 조회

창고 회전율 향상을 위해 보관일수 임계값 기준 장기 재고를 추적 및 관리합니다.

  • 센터그룹·센터·고객사·존·재고상태 다중 검색 조건 모듈 구현
  • 사용자 정의 보관일수 조건 기반의 장기 재고 필터링 알고리즘 적용
  • 상품코드·상품명·상품상태·총 재고수량·가용 수량 현황 그리드 표시
  • 입고일자·생산일자·유통기한·소비기한·로케이션·재고SEQ 상세 정보 연계

상품별 현재고현황

재고 품질 속성(일반/보류/불량) 및 로케이션 단위 재고 상세를 다각도로 모니터링합니다.

  • 센터그룹·센터·고객사·상품·존·재고상태 복합 검색 엔드포인트 구현
  • 상품명·상품바코드·Box입수량·판매가·총수량 등 상품 마스터 속성 산출
  • 일반존·보류존·불량존 재고 등 품질 유형별 분류 집계 로직 적용
  • 하단 로케이션 그리드에 재고SEQ·존·로케이션·수불구분코드·상품상태·LOT 바인딩
  • 입고일자·생산일자·상품일련번호·총수량·가용수량 단위별 실시간 상태 확인

진행중인 재고현황

현재 재고와 입고·출고·반출·조정·이동·변경 등 수불 진행 중 수량을 통합 집계합니다.

  • 센터그룹·센터·고객사·상품·재고상태 기준 실시간 수불 파이프라인 구현
  • 상품별 현 재고(재고수량·가용수량·차이수량) 자동 연산 및 그리드 바인딩
  • 수불 진행 수량(총수량·입고·출고·반출·조정·이동·변경) 통합 Pivot 조회 구현
  • 대량 상품 데이터 목록의 실시간 재고 변동 흐름 트래킹 지원

주요 화면

입고예정 관리

센터그룹·센터·고객사·입고처 조건으로 입고예정 목록을 조회하는 화면입니다. 상단 입고예정 목록과 하단 상품정보(환산 예정·등록수량)를 분리하여 연계 표시합니다.

입고등록 관리

입고예정 목록을 선택하여 실제 입고를 처리하는 화면입니다. 상품코드·존·로케이션·로트·유통기한 등 상품 상세 정보를 등록하고 저장합니다.

출고예정 조회

출고예정 목록과 상품 상세 정보를 조회하는 화면입니다. 출고진행상태·보세여부·출고배치 등 다양한 조건으로 출고 현황을 파악합니다.

출고예정 상품정보

출고예정 선택 시 하단에 연계 표시되는 상품 상세 화면입니다. 고객라인번호·상품코드·검수용바코드·환산 예정·등록·확정수량을 확인합니다.

센터별 재고 조회

좌측 상품 목록과 우측 센터·로케이션별 재고 상세 정보를 연계 표시합니다. 상품 선택 시 해당 센터의 존·로케이션별 재고수 및 가용재고수를 즉시 조회합니다.

장기보관 상품 조회

보관일수 기준으로 장기 보관 중인 상품 목록을 조회하는 화면입니다. 재고상태·존 조건과 입고일자·유통기한·소비기한·로케이션 정보를 함께 확인합니다.

상품별 현재고현황

상품별 총수량·일반/보류/불량존재고를 집계하여 표시하는 화면입니다. 하단 로케이션별 재고정보에서 LOT·상품상태·입고일자별 상세 수량을 확인합니다.

진행중인 재고현황

현 재고(재고·가용·차이수량)와 진행수량(입고·출고·반출·조정·이동·변경)을 통합 조회합니다. 상품별 재고 변동 흐름을 한 화면에서 실시간으로 파악할 수 있습니다.

트러블 슈팅

대용량 재고 집계 쿼리 및 Vue.js 그리드 렌더링 성능 최적화

센터별 재고 및 진행중인 재고현황 화면에서 상품 데이터 증가 시 발생하던 다중 GROUP BY 연산 지연 및 프론트엔드 그리드 DOM 병목 현상을 해결했습니다.

문제 상황

  • 재고 집계 쿼리 실행 시 데이터 누적으로 인한 DB Response Time 저하
  • 다중 테이블 JOIN 및 SUM/GROUP BY 연산으로 인한 DB CPU 사용량 폭증
  • Vue.js 그리드 컴포넌트에 수십 개 컬럼 병렬 바인딩 시 DOM 스크롤 렌더링 지연 발생

원인 분석

  • `EXPLAIN PLAN` 분석 결과 검색 주요 조건절의 Table Full Scan 구간 발견
  • `센터코드`, `상품코드`, `존코드` 복합 인덱스 부재로 인한 조인 성능 저하 확인
  • 불필요한 서브쿼리의 반복 실행 및 불필요한 전체 컬럼(`SELECT *`) 조회 확인

개선 작업

  • 조회 빈도가 높은 검색 조건 컬럼 대상 복합 인덱스(Composite Index) 생성
  • 중복 실행되는 서브쿼리를 인라인 뷰(Inline View)로 재작성 및 SELECT 컬럼 최소화
  • PostgreSQL Query Hint 적용 및 백엔드 Server-side Pagination 처리로 데이터 로드 범위 제한
  • Vue.js 그리드 렌더링 시 Virtual Scroll 기법 적용으로 프론트엔드 과부하 방지

결과

  • 재고 집계 조회 응답 속도 대폭 개선 및 DB I/O 부하 절감
  • Vue.js 그리드 데이터바인딩 지연 현상 완화로 UI 쾌적성 확보

동시 수불 처리 시 진행중인 재고 수량 불일치 조치

입·출고가 동시에 발생하는 상황에서 현 재고수량과 진행 수량의 합산 결과가 실제 가용수량과 일치하지 않는 트랜잭션 정합성 오류를 해결했습니다.

문제 상황

  • 실시간 입출고 동시 처리 시 특정 재고 조건에서 차이수량이 비정상적으로 계산됨
  • 간헐적으로 진행 중 수량과 현 재고의 불일치가 발생하여 데이터 신뢰도 저하

원인 분석

  • 수불 진행 상태 조건 분기 Java 로직에서 특정 재고상태 Enum 누락 확인
  • PostgreSQL SQL 집계 시 `NULL` 값에 대한 예외 처리 미비로 연산 시 누락 발생 확인

개선 작업

  • 쿼리 내 `COALESCE` / `NVL` 연산 처리를 통한 NULL 집계 예외 완벽 보정
  • 재고 상태별 조건 분기 로직 완전 재설계 및 누락된 수불 상태 케이스 추가
  • 동시성 테스트용 단위 테스트 케이스(Junit) 구축을 통한 수량 정합성 검증

결과

  • 동시 수불 트랜잭션 환경에서도 재고 집계 정확도 100% 확보
  • 실시간 재고 데이터의 신뢰성 확보 및 물류 운영 업무 안정화

프로젝트 성과

  • 입고예정·입고등록·출고예정 등 물류 창고 라이프사이클 전반을 통합 제어하는 핵심 WMS 모듈 성공적 구현
  • 센터·존·로케이션 및 LOT 단위의 정밀한 재고 추적 체계를 구축하여 실시간 재고 가시성 확보
  • 장기보관 상품 조회 및 필터링 기능 도입을 통해 창고 공간 효율화 및 악성 재고 관리 기여
  • 입/출고·이동·조정 등 수불 상태를 통합 파악할 수 있는 Pivot 형태의 진행재고 대시보드 구축
  • PostgreSQL 집계 쿼리 튜닝 및 복합 인덱스 설계를 통해 대용량 재고 조회 성능 최적화 달성
  • 입출고 수불, 로케이션 배치, 유통기한 관리, LOT 트래킹 등 전문 물류 도메인 지식 체득
  • 요구사항 분석부터 DB 설계, API 구현, UI 개발, 성능 테스트 및 배포까지 전체 개발 프로세스 완수
