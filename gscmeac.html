SCM / e-Accounting 시스템 유지보수 및 기능 개선

2024.12 ~ 2026.07

프로젝트 개요

전자정부프레임워크 기반 SCM(공급망 관리) 및 e-Accounting(전자 회계) 시스템의 정기 유지보수 및 고도화 운영 업무입니다.

발주 접수, 납품 현황, 입고 마감 등의 SCM 프로세스와 5가지 전표 유형(법인카드, 세금계산서, 일반전표 등)의 결재 및 승인 워크플로우를 담당하여 안정성을 보장하였습니다.

기술 스택

Java JavaScript 전자정부프레임워크 Oracle PostgreSQL Nexacro MyBatis

담당 업무

  • Nexacro 화면 수정 및 Java 비즈니스 로직 고도화
  • SCM 발주/납품/마감 데이터 쿼리 오류 분석 및 수정
  • e-Accounting 다단계 결재(부서결재 → 회계승인) 워크플로우 개선
  • 운영 중 예외 장애 분석 및 데이터 정합성 검증

트러블 슈팅

납품 집계 데이터 불일치 및 전표 결재 트랜잭션 오류 해결

문제 상황

  • 납품 현황 집계 시 특정 상태 수량이 중복 계산되는 현상
  • 일괄 상신 시 트랜잭션 예외 발생으로 일부 전표 상태 불일치

개선 작업

  • GROUP BY 집계 쿼리 전송 상태 분기 로직 보완 및 NVL 보정
  • 결재 단계 트랜잭션 예외 처리 강화 및 명시적 롤백 적용

결과

  • 납품 집계 정확도 100% 달성 및 결재 워크플로우 장애 발생률 현저 감소

프로젝트 성과

  • 복잡한 쿼리 최적화로 화면 응답 속도 기존 대비 30% 개선
  • 전자정부프레임워크 및 Nexacro 기반 운영 환경 숙련도 확보
  • 운영 장애 발생 시 원인 추적 및 신속 대응 프로세스 체득
