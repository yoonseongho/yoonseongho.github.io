창고관리시스템 (WMS) 고도화

2023.09 ~ 2023.12 (4개월)

프로젝트 개요

입고·출고·재고 등 창고 물류 업무 전반을 관리하는 창고관리시스템(WMS) 고도화 프로젝트입니다. 센터·존·로케이션 단위의 재고 조회, LOT 및 유통기한 관리, 입고·출고·이동·조정 등 재고 수불 현황을 확인할 수 있는 기능을 개발하여 재고 관리의 가시성과 업무 효율성을 높이는 데 기여했습니다.

기술 스택

Java Spring Boot Vue.js PostgreSQL MyBatis REST API

담당 업무 Summary

  • 입·출고 프로세스: 입고예정·입고등록·출고예정 화면 및 연계 상품 정보 조회 기능 개발
  • 재고 모니터링: 센터별 재고 조회, 상품·로케이션 연계 화면 및 장기보관 재고 조회 기능 구현
  • 수불 집계 대시보드: 현재고와 입고·출고·이동·조정 등 진행 중인 수불 현황을 통합 조회하는 기능 개발
  • 조회 성능 개선: PostgreSQL 인덱스 및 쿼리 개선, 대량 데이터 화면 처리 방식 최적화

주요 기능

1. 입·출고 관리 및 단위 환산

센터 및 고객사 기준의 입·출고 업무 흐름을 지원하고, 상품별 포장 단위에 따른 수량을 관리할 수 있도록 기능을 구현했습니다.

  • PLT / BOX / CS / EA 단위 간 환산 수량 계산 로직 구현
  • LOT, 생산일자, 유통기한 및 잔여 유통일수 관련 정보 처리
  • 입고예정 정보와 상품 상세 정보를 연계하고 실제 입고 등록 및 확정 처리 지원
  • 출고예정 상태와 출고 대상 상품 정보를 조회하고 확정 수량을 확인할 수 있는 화면 개발

2. 재고 조회 및 수불 현황 대시보드

센터·존·로케이션별 재고 현황과 진행 중인 수불 내역을 조회하여 창고 운영 상황을 파악할 수 있는 기능을 개발했습니다.

  • Master-Detail(Split UI) 구조를 적용해 상품 선택 시 센터 및 로케이션별 재고 상세 정보를 연계 조회
  • 보관일수 기준의 장기보관 재고 조회 기능 구현
  • 일반·보류·불량 등 재고 상태별 수량 조회 기능 개발
  • 현재고와 입고·출고·반출·조정·이동 등 진행 수량을 통합 조회하는 집계 기능 구현

주요 화면

입고예정 관리

입고예정 목록과 연계 상품 정보를 구분하여 조회하고 환산 수량 확인

입고등록 관리

로케이션·LOT·유통기한 정보 입력 및 실제 입고 확정 처리

출고예정 조회

출고 진행 상태 및 보세 여부 등 다양한 조건에 따른 출고예정 정보 조회

출고예정 상품정보

출고 대상 상품의 바코드 정보 연계 및 확정 수량 확인

센터별 재고 조회

상품 마스터와 센터·로케이션별 재고 상세 정보를 연계한 Split UI

장기보관 상품 조회

보관일수 기준으로 장기보관 상품을 조회하고 재고 상태 확인

상품별 현재고 현황

일반·보류·불량 재고 상태별 집계 및 로케이션별 수량 조회

진행 중인 재고 현황

현재고와 입고·출고·이동·조정 등 진행 중인 수불 수량 통합 조회

트러블 슈팅 (Problem Solving)

1. 재고 집계 쿼리 및 프론트엔드 그리드 성능 개선

문제 및 원인

재고 집계 과정에서 다중 GROUP BY 및 SUM 연산으로 조회가 지연되고, 다량의 데이터를 화면에 바인딩할 때 브라우저 렌더링과 스크롤 반응이 저하되는 문제가 있었습니다.

해결 방안

  • 센터·상품·존 등 주요 조회 조건에 사용되는 컬럼의 인덱스를 검토하고 복합 인덱스 적용
  • 불필요한 서브쿼리와 집계 로직을 점검하여 조회 쿼리 구조 개선
  • 대량 데이터 화면의 렌더링 부담을 줄이기 위해 Virtual Scroll 등 화면 처리 방식 검토 및 적용

결과

데이터베이스 조회와 화면 렌더링 과정의 불필요한 처리 부담을 줄여 재고 조회 화면의 사용성과 데이터 처리 효율 개선에 기여했습니다.

2. 수불 진행 상태에 따른 재고 집계 불일치 해결

문제 및 원인

수불 진행 상태별 조건 분기가 충분히 반영되지 않거나, PostgreSQL 집계 과정에서 NULL 값이 처리되지 않아 진행 재고 수량에 차이가 발생하는 문제가 있었습니다.

해결 방안

  • COALESCE를 적용해 NULL 값에 대한 집계 처리 기준 보완
  • 입고·출고·이동·조정 등 수불 상태별 조건 분기 로직 점검 및 개선
  • 다양한 수불 상태와 수량 조합을 기준으로 집계 결과 검증

결과

수불 상태 및 NULL 값에 따른 집계 예외를 보완하여 현재고와 진행 재고 데이터의 일관성을 개선했습니다.

프로젝트 성과

  • 재고 가시성 개선: 센터·존·로케이션 및 LOT 관련 정보를 활용해 재고 현황을 세분화하여 조회할 수 있는 환경 구축
  • 수불 데이터 정합성 개선: 수불 상태별 집계 로직과 NULL 처리 보완을 통해 진행 재고 조회의 일관성 향상
  • 재고 관리 업무 지원: 장기보관 상품 조회 기능을 통해 장기 체류 재고의 확인 및 관리 지원
  • 조회 성능 개선: PostgreSQL 쿼리와 인덱스 구조를 검토하고 대량 데이터 화면 처리 방식을 개선
