CRM 시스템 구축

2025.11 ~ 2026.05

Vue.js · AG-Grid 기반 영업 데이터 관리 및 견적·계약·전자결재 UI 개발

프로젝트 개요

고객 정보, 영업 견적, 계약 및 전자결재 이력을 통합 관리하는 CRM 시스템입니다. Vue.js 기반 업무 화면과 AG-Grid 데이터 조회 기능을 개발하고, REST API 연동 및 데이터 조회 흐름을 개선했습니다.

기술 스택

Vue.js JavaScript HTML / CSS AG-Grid REST API Java Spring Boot PostgreSQL Git

담당 업무

  • 견적 등록·수정 및 품목별 금액 입력 화면 개발
  • AG-Grid 기반 견적·계약 목록과 검색·정렬·필터링 구현
  • 계약 상태 및 상세 정보 조회 UI 개발
  • 전자결재 문서 목록·상세 정보 Split View 구현
  • REST API 연동 및 데이터 표시 흐름 개선

주요 구현 기능

1. 견적 등록 및 조회

고객사·프로젝트별 견적 입력과 다량의 견적 데이터를 조회하는 화면을 개발했습니다.

  • 견적 품목, 단가, 수량 등 입력 UI 구성
  • AG-Grid 기반 목록 및 검색 조건 구현
  • 견적 상세 정보와 품목 목록 조회 화면 개발

2. 계약 관리

계약 현황과 진행 상태를 검색하고 상세 정보를 확인할 수 있도록 구현했습니다.

  • 계약번호·거래처 기반 검색 기능
  • 계약 상태별 필터링 및 상세 조회
  • 계약 금액과 첨부파일 정보 표시

3. 전자결재 문서함

결재 문서 목록과 상세 내용을 한 화면에서 확인할 수 있도록 구성했습니다.

  • 목록·상세 정보 Split View 구현
  • 문서번호·결재 양식·승인 상태 검색
  • 결재 이력 및 문서 유형별 본문 표시

주요 화면

견적 등록

견적 입력 폼과 품목 정보를 관리하는 화면

견적 조회

검색 조건과 AG-Grid를 활용한 견적 목록 조회

기안문서함

결재 문서 목록과 상세 내용 및 결재 이력 확인

계약 조회

계약 상태·금액·첨부파일 정보 조회

트러블 슈팅

대량 데이터 조회 시 그리드 응답성 저하

문제

견적 및 계약 데이터가 증가하면서 목록 조회와 그리드 표시가 지연됐습니다.

개선 작업

  • SQL 실행계획 및 검색 조건의 인덱스 활용 여부 점검
  • 불필요한 JOIN과 조회 컬럼 검토
  • 그리드 데이터 전달 및 표시 과정 개선

결과

조회 데이터 처리 흐름을 점검하고 불필요한 데이터 조회를 줄여 화면 응답성 개선에 기여했습니다.

프로젝트 성과

  • Vue.js 기반 견적·계약·전자결재 업무 화면 개발
  • AG-Grid를 활용한 데이터 검색·정렬·필터링 구현
  • 목록과 상세 정보를 연결한 Split View UI 구성
  • API 및 SQL 조회 흐름 점검을 통한 화면 응답성 개선
