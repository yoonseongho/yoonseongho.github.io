SCM / e-Accounting 시스템 운영 및 유지보수

2024.01 ~ 현재

프로젝트 개요

Kolmar BNH의 핵심 서비스인 공급망 관리 시스템(SCM)과 전자 회계 시스템(e-Accounting)의 안정적인 운영을 위한 기능 개선 및 시스템 유지보수 프로젝트입니다.

SCM: 발주 접수, 납품예정 등록, 납품 현황 조회, 입고실적 마감 등 구매·물류 업무 전 과정의 오류를 조치하고 집계 로직을 개선하였습니다.

e-Accounting: 법인카드, 세금계산서, 일반전표, 개인경비 등 5개 전표 유형의 상신·결재·승인 워크플로우를 유지보수하고 트랜잭션 처리 과정의 데이터 정합성을 개선하였습니다.

기술 스택

Java JavaScript Spring Framework Oracle MyBatis REST API GitLab

담당 업무

  • SCM 발주 및 납품 프로세스 개선: 발주 접수, 납품예정 등록 및 시간대별·마감 기준 납품 현황 조회 로직 개선
  • 물류 데이터 정합성 관리: 구매 잔여 수량 산출 및 제품 입고·마감 집계 쿼리 오류 수정
  • 전표 워크플로우 유지보수: 법인카드·세금계산서·일반전표 등 전표 유형별 일괄 상신 및 후속 증빙 연계 로직 보완
  • 결재·승인 프로세스 안정화: 부서 결재 및 회계 담당자·팀장 승인 단계별 상태 전환 오류 조치와 일괄 처리 트랜잭션 보완
  • 운영 지원: 운영 장애 대응, 엑셀 다운로드 등 업무 편의 기능 개선 및 레거시 코드 리팩토링

주요 기능

발주 및 납품 관리 (SCM)

구매·납품 업무의 핵심인 발주서 접수부터 시간대별·단가별 납품 집계까지 관련 프로세스를 유지보수하고 개선하였습니다.

  • 발주 미접수 건 필터링 및 발주 알림 로직 개선
  • 납품예정 등록 및 고객사 전송 시 상태값 갱신 오류 조치
  • 발주서별·시간대별 납품 현황 집계 및 차트 표시 로직 개선
  • 구매 잔여량 산출 SQL 로직 보완을 통한 데이터 정합성 확보

전표 생성 및 상신 (e-Accounting)

법인카드, 세금계산서, 일반전표, 개인경비 등 다양한 유형의 전표 처리 및 증빙 연계 기능을 보완하였습니다.

  • 전표 유형별 생성 화면 UI/UX 개선 및 예외 처리 로직 추가
  • 다건 전표 일괄 상신 및 전표 그룹 상신 시 트랜잭션 처리 보완
  • 세금계산서 및 일반전표 후속 증빙 연동 기능 개선

다단계 결재 및 승인 워크플로우 (e-Accounting)

부서 결재부터 회계팀 최종 승인까지 이어지는 결재 프로세스의 상태 전환 및 승인 처리 로직을 개선하였습니다.

  • 부서 결재 후 승인 대기 목록에 전표가 표시되지 않는 문제 조치
  • 회계 담당자·팀장 전표 일괄 승인 및 반려 처리 시 동시성·예외 처리 보완
  • 전표 현황 조회 및 엑셀 다운로드 기능 개선

트러블 슈팅

1. 납품 현황 집계 데이터 불일치 해결

마감 기준 납품 현황 화면의 수치와 납품예정 등록 수량이 일치하지 않고 일부 데이터가 중복 집계되는 문제를 해결하였습니다.

원인 분석

  • GROUP BY 집계 쿼리에서 고객사 전송 상태에 따른 조건 분기 누락
  • 전송 처리 후 DB 상태값이 갱신되지 않아 동일 건이 중복 집계되는 문제 확인

조치 및 결과

  • 전송 상태 조건 분기를 추가하고 NVL 처리를 통해 NULL 집계 오류 보정
  • 전송 프로세스 완료 후 상태값이 정상 반영되도록 트랜잭션 처리 보완
  • 성과: 미전송·전송 데이터의 집계 정합성을 개선하고 마감 업무의 신뢰도 향상

2. 전표 결재 워크플로우 상태 누락 및 트랜잭션 오류 해결

부서 결재 후 승인 화면에서 전표가 누락되거나, 일괄 상신 시 일부 전표의 상태값이 갱신되지 않는 문제를 조치하였습니다.

원인 분석

  • 단계별 상태 전환 로직에서 특정 전표 유형에 대한 처리 분기 누락
  • 일괄 상신 처리 중 일부 전표에서 오류가 발생했을 때 예외 및 트랜잭션 처리가 미흡한 문제 확인

조치 및 결과

  • 전표 유형별 상태 전환 분기 로직을 점검하고 누락된 처리 케이스 보완
  • 일괄 상신 과정의 예외 처리 및 트랜잭션 롤백 로직 개선
  • 성과: 결재 상태 누락 문제를 개선하고 회계 결재 워크플로우 안정성 향상

프로젝트 성과

  • 업무 프로세스 안정화: 발주·납품·입고로 이어지는 SCM 프로세스의 오류를 조치하고 처리 효율 개선
  • 회계 결재 정합성 개선: 다양한 전표 유형의 다단계 결재 및 일괄 승인 워크플로우 오류 개선
  • 데이터 정확도 향상: 집계 쿼리와 조건 분기를 보완하여 마감 데이터 정합성 개선
  • 운영 역량 강화: 실서비스 레거시 시스템 분석, 운영 장애 대응 및 코드 리팩토링 경험 축적
