Vue.js와 AG-Grid 기반의 프론트엔드 및 Spring Boot REST API를 활용했으며, 사용자 업무 동선을 고려한 Split UI 구성과 데이터 조회 성능 개선을 진행했습니다.

**주요 기능**

  - 입력 데이터 유효성 검증 및 예외 처리
  - 견적 상태 변경 및 변경 이력 관리

- **견적 조회**
  - AG-Grid 기반 견적 목록 화면 구현
  - 견적번호, 고객사명, 프로젝트명 등 복합 조건 검색
  - 컬럼 정렬 및 다중 조건 필터링
  - 견적 상세 내역 및 품목 리스트 조회

- **계약 조회**
  - 계약번호 및 거래처 기준 검색
  - 승인 대기, 체결, 파기 등 계약 상태별 조회
  - 계약 상세 정보 및 계약 금액 확인
  - 계약 관련 첨부파일 조회
  - 견적 데이터와 계약 정보 연계 조회

- **기안문서함**
  - 기안 및 결재 문서 목록 조회
  - 문서 목록과 상세 내용을 좌우 분할형 UI로 구성
  - 결재선 및 승인 이력 확인
  - 열람자 및 참조자 정보 확인

- 조회 조건과 사용 빈도를 고려한 고객사·견적일자·담당자 컬럼 복합 인덱스 적용
- 필요한 컬럼만 조회하도록 SQL 정리
- 불필요한 OUTER JOIN 제거
- 반복 조회되는 마스터 데이터의 캐싱 적용 가능성 검토
- 조회 데이터 처리 구조를 개선하여 불필요한 DB 조회 부담 감소

이를 통해 목록 조회와 그리드 초기 표시의 응답성을 개선하고 검색 화면의 사용성을 높였습니다.

**기술 스택**

Java, Spring Boot, Vue.js, PostgreSQL, REST API, AG-Grid, Git

## 🎯 Development Philosophy

### 사용자에게 편리한 서비스를 만드는 개발자

개발자가 구현하기 편한 방식보다 실제 사용자가 이해하고 사용하기 쉬운 화면과 기능을 만드는 것이 중요하다고 생각합니다. 사용자의 업무 흐름을 파악하고 불필요한 작업을 줄일 수 있는 방향으로 화면과 기능을 고민합니다.

### 원인을 파악하고 해결하는 개발자

오류가 발생했을 때 단순히 결과만 수정하는 것이 아니라 문제가 발생한 원인을 분석하고 해결하는 과정을 중요하게 생각합니다. 화면, API, 서버 로직, 데이터베이스 등 여러 단계에서 발생할 수 있는 문제를 확인하며 해결 방법을 찾아갑니다.

### 유지보수하기 좋은 코드를 고민하는 개발자

프로젝트는 기능을 구현하는 것으로 끝나는 것이 아니라 지속적으로 운영되고 개선되는 과정이라고 생각합니다. 코드의 구조와 데이터 흐름을 이해하고, 추후 기능 변경이나 확장에도 대응할 수 있는 개발을 지향합니다.

### 꾸준히 배우고 성장하는 개발자

새로운 기술과 개발 환경에 관심을 가지고 학습하며, 배운 내용을 실제 업무에 적용할 수 있도록 노력합니다. 다양한 프로젝트를 경험하면서 프론트엔드뿐만 아니라 백엔드와 데이터베이스에 대한 이해도 함께 넓혀가고 있습니다.

## 🚀 Goal

앞으로는 프론트엔드 개발 역량을 더욱 깊이 있게 발전시키고, 서비스 전체의 구조와 데이터 흐름을 이해하는 개발자로 성장하고자 합니다.

다양한 실무 프로젝트에서 쌓은 화면 개발, API 연동, 데이터 처리 및 시스템 유지보수 경험을 바탕으로 사용자 경험과 서비스 안정성을 함께 고려하는 개발자가 되겠습니다.

주어진 요구사항을 구현하는 데 그치지 않고, 문제를 발견하고 개선 방향을 제안하며 더 나은 서비스를 만들어가는 개발자가 되는 것이 목표입니다.

**사용자의 입장에서 고민하고, 코드의 품질을 생각하며, 지속적으로 성장하는 개발자 윤성호입니다.**
