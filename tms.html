TMS 시스템 개발 및 고도화

2024.01 ~ 2025.01

프로젝트 개요

관세청 보세운송, 항공, 내륙 운송 등 다양한 운송 업무를 지원하는 TMS(Transportation Management System) 구축 프로젝트입니다.

운임, 선사, 차량(14,000건+), 기사, 샤시 등 대규모 물류 기초코드를 체계적으로 관리하고, 거점(Location/Depot) 정보 연동 및 배치 프로그램 모니터링을 담당하였습니다.

실적 및 청구 분석 화면을 통해 정산 정확성을 향상시켰으며, 대용량 데이터 페이징 기법을 적용하여 UI 렌더링 및 쿼리 응답 속도를 개선했습니다.

기술 스택

Java Vue.js Spring Boot PostgreSQL MyBatis REST API GitLab

담당 업무

  • 운임, 선사, 차량, 기사, 샤시 등 물류 핵심 기초코드 관리 기능 전반 개발
  • Location/Depot 거점 정보 및 COPINO EDI 연계 관리 화면 개발
  • 14,000건 이상 대용량 차량 데이터 페이징 및 최적화
  • 배치(Batch) 프로그램 개발, 예외 처리 개선 및 로그 분석 체계 구축
  • 월간 실적 및 컨테이너별 청구·비용 대비 분석 화면 구현

주요 기능

차량 및 기사 관리 (14,000건+)

협력사 차량 및 기사 정보를 모듈화하여 관리했습니다.

  • 14,722건 대용량 차량 데이터 페이징 처리로 메모리 부하 절감
  • 기사 정보(5,014건) APP 전송 및 계약 기간 연동 관리

Location / Depot 관리

운송 거점 및 Depot 정보를 통합 관리하는 연계 화면을 구성했습니다.

  • COPINO EDI 연계 정보 및 보세구역 설정 관리

월간 실적 및 청구 대비 분석

매출, 비용, 이익율을 자동 산출하는 정산 지원 화면을 구현했습니다.

  • 컨테이너 단위 I/O 구분 및 청구 대비 비용 자동 집계

주요 화면

운임코드 관리

상단 입력 폼과 하단 코드 목록을 분리하여 220건 이상의 운임코드를 관리합니다.

차량코드 관리

14,722건의 대용량 차량 목록을 탭 구조와 페이징으로 원활하게 처리합니다.

Location / Depot 관리

Location 목록과 Depot 상세 정보를 좌우 분할로 연계 표시합니다.

월간 실적 조회

월 단위 운임별 매출, 비용, 이익을 집계하여 시각화합니다.

트러블 슈팅

대용량 차량/기사 데이터 조회 및 배치 안정화

문제 상황

  • 14,000건 이상의 대용량 기초 데이터 조회 시 브라우저 렌더링 지연 및 DB 부하 발생

개선 작업

  • ROWNUM 기반 DB 페이징 처리 도입 및 불필요한 SELECT 컬럼 제거
  • 배치 오류 예외 처리 보완 및 로그 추적을 통한 자동 사전 감지 로직 적용

결과

  • 조회 속도 대폭 개선 및 배치 프로그램 성공률 99% 달성

프로젝트 성과

  • 14,000건+ 대용량 차량 데이터 페이징 및 PostgreSQL SQL 튜닝 기술 확보
  • 배치 예외 처리 강화로 실무 운영 중 서비스 다운타임 극소화
  • 보세운송, 컨테이너, 샤시 등 물류 전문 도메인 지식 습득
