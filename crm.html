CRM 시스템 구축

2025.11 ~ 2026.05

프로젝트 개요

고객 정보, 영업 견적, 계약 파이프라인 및 결재 이력을 통합 관리하기 위한 신규 CRM(Customer Relationship Management) 구축 프로젝트입니다.

영업 담당자가 영업 기회 발굴부터 계약 체결까지의 워크플로우를 효율적으로 관리할 수 있도록 견적 등록·조회, 계약 모니터링, 전자결재 연동 모듈을 개발하였습니다.

Vue.js와 AG-Grid 기반의 프론트엔드, Spring Boot REST API를 활용해 기능을 구현했습니다. 사용자 업무 흐름을 고려한 분할형(Split) UI를 적용하고 조회 SQL 및 그리드 화면의 성능 개선을 진행했습니다.

기술 스택

Java Spring Boot Vue.js PostgreSQL REST API AG-Grid Git

담당 업무

  • 고객사·프로젝트 연계 견적 등록 및 수정 처리 모듈 개발
  • AG-Grid 기반 다기능 견적 조회 및 필터링 파이프라인 구축
  • 계약 상태 파이프라인 및 계약 이력 조회 모듈 개발
  • Spring Boot 기반 RESTful API 개발 및 요청·응답 데이터 처리
  • Vue.js 반응형 UI 개발 및 컴포넌트 단위 REST API 바인딩
  • PostgreSQL 복합 조회 쿼리 작성 및 실행계획 분석을 통한 SQL 개선
  • 현업 요구사항 분석, UX/UI 개선 및 장애 대응 지원

주요 기능

견적 등록 기능

고객사 및 영업 프로젝트 기반의 상세 견적 데이터를 체계적으로 등록·수정하는 모듈입니다.

  • 고객사 매핑 및 프로젝트 연계 기반 견적 데이터 트랜잭션 구현
  • 견적 세부 품목별 단가·수량·가공비 연산 및 최종 금액 자동 산출
  • 입력 값 유효성 검증(Validation) 및 예외 처리 핸들러 적용
  • 견적 상태 변경 및 변경 이력 추적 REST API 구축
  • 견적 문서 데이터 히스토리 관리 및 버전 트래킹 기능 구현

견적 조회 기능

AG-Grid를 활용해 다량의 견적 데이터를 탐색·검색할 수 있는 반응형 화면입니다.

  • AG-Grid 기반 견적 목록 및 조건 검색 컴포넌트 구축
  • 견적번호, 고객사명, 프로젝트명 복합 조건 실시간 검색 구현
  • 컬럼 정렬 및 다중 조건 필터링 기능 구현
  • 견적 상세 내역 및 품목 리스트 조회를 위한 팝업/모달 모듈 개발
  • 검색 편의성을 고려한 사용자 맞춤 UI 레이아웃 구성

계약 조회 기능

체결된 계약 현황과 상태별 진행 파이프라인을 조회하고 추적합니다.

  • 계약번호 및 거래처 기준 멀티 파라미터 검색 기능 구축
  • 계약 상태(승인대기·체결·파기 등)별 조건 필터링 구현
  • 계약 상세 정보 및 하단 계약금액/첨부파일 통합 폼 구성
  • 견적 데이터와 계약 정보 간 연계 조회 기능 구현

기안문서함 기능

내부 전자결재 워크플로우와 연동하여 결재 기안 및 진행 상태 모니터링을 제공합니다.

  • 기안/결재 문서 목록 및 상세 페이지 Split View 구성
  • 결재 양식, 승인 상태, 문서번호 기반 다차원 조건 검색 지원
  • 결재선(기안-검토-승인) 이력 및 열람/참조자 정보 확인 기능 구현
  • 휴가신청서, 지출결의서 등 양식 유형별 결재 본문 동적 렌더링

주요 화면

견적 등록

견적 목록과 상세 입력 폼을 좌우 분할 레이아웃으로 구성하였습니다. 견적 기간·타입·담당자 등 다양한 검색 조건을 제공하며, 첨부파일 업로드와 견적 비용 리스트 관리 기능을 함께 제공합니다.

견적 조회

AG-Grid 기반의 견적 목록 조회 화면입니다. 거래처구분·견적타입·담당자 조건 검색을 지원하며, 하단에 견적금액 리스트와 합계를 함께 표시합니다.

기안문서함

기안 문서 목록과 결재 상세 정보를 좌우 분할로 표시합니다. 결재 이력과 열람/참조자 정보를 확인할 수 있으며, 결재내용을 양식별로 렌더링합니다.

계약 조회

계약 목록 그리드와 하단 상세 폼을 수직으로 구성하였습니다. 계약 기간, 거래처구분, 계약타입, 승인상태 조건 검색을 지원하며, 계약금액 리스트와 첨부파일 리스트를 하단 좌우에 나란히 배치하였습니다.

트러블 슈팅

대용량 견적/계약 데이터 조회 및 복합 조인 SQL 성능 최적화

견적 및 계약 데이터가 증가하면서 복합 JOIN 조회가 느려지고, AG-Grid 초기 렌더링이 지연되는 문제를 개선했습니다.

문제 상황

  • 견적·고객사·품목 테이블 간 복합 JOIN으로 조회 응답 시간 증가
  • 검색 조건에 적합한 인덱스가 활용되지 않아 전체 스캔 및 DB 부하 발생
  • AG-Grid 전체 로딩 시 메모리 사용량 증가로 인한 화면 버벅임 현상

원인 분석

  • EXPLAIN 실행계획을 확인해 검색 조건 컬럼의 인덱스 활용 여부 점검
  • SELECT * 조회로 인해 화면에 필요하지 않은 컬럼까지 조회되는 부분 확인
  • 정렬 조건과 실행계획을 점검해 디스크 기반 정렬이 발생하는 구간 확인

개선 작업

  • 조회 조건과 사용 빈도를 검토해 고객사·견적일자·담당자 컬럼의 복합 인덱스 적용
  • 필요한 컬럼만 조회하도록 SQL을 정리하고 불필요한 OUTER JOIN 제거
  • 반복 조회되는 마스터 데이터의 캐싱 적용 가능성을 검토해 DB 반복 조회 부담을 줄이는 방향으로 개선

결과

  • 불필요한 데이터 조회를 줄여 목록 조회와 그리드 초기 표시의 응답성을 개선
  • 검색 조건에 맞는 조회 처리와 화면 반응성 개선

프로젝트 성과

  • 견적 등록·조회 및 계약 관리 기능을 통합해 영업 데이터의 일관된 관리 지원
  • 고객사별 영업 이력, 견적, 계약 데이터를 통합 수집·조회할 수 있는 파이프라인 구축
  • 계약 모니터링 및 상태 추적 모듈을 구축하여 영업 누락 방지 및 운영 업무 지원 강화
  • RESTful API와 DTO/Entity 분리를 적용해 요청·응답 데이터 처리 구조를 정리
  • PostgreSQL 쿼리 실행계획 분석, 인덱스 최적화 및 튜닝을 통한 데이터 조회 개선 경험 확보
  • 요구사항 분석부터 개발 및 테스트까지 프로젝트 단계별 업무 수행
